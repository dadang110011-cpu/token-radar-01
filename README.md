A token launch radar: 289 pre-token protocols from a sealed DefiLlama snapshot (14 November 2026), ranked by an implied launch value derived from TVL, seven-day growth, age with no token, chain diversity and the category's tokenisation rate — with a concrete farm plan for each, in a static dashboard. The board covers the whole 40-protocol watchlist plus every other rankable pre-token protocol, ranked by the model's score rather than raw TVL.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
